# Ticket PDF fonts

Noto Sans Regular and Bold are bundled to support the naira symbol and accented Latin passenger names in downloaded PDFs. They are embedded as subsets by PDFKit; ticket generation does not make network requests.

Source: [Noto Fonts repository](https://github.com/notofonts/noto-fonts), downloaded 21 September 2026:

- [NotoSans-Regular.ttf](https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf)
- [NotoSans-Bold.ttf](https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Bold.ttf)
